# Prompt Design

| Prompt | Version | Purpose |
| --- | --- | --- |
| Feedback Analyzer | `feedback-analyzer-v1` | Controlled classification and underlying need. |
| Pain Point | `pain-point-v1` | Consolidation with real evidence IDs. |
| Requirement | `requirement-v1` | Requirement extraction without business-value decisions. |
| Opportunity | `opportunity-v1` | Conservative exploration directions and risks. |
| PRD | `prd-v1` | Evidence-backed structured draft. |

Prompts prohibit invented counts, business context, market data, baselines, and evidence IDs. The severity rubric limits inflation. Ambiguity lowers confidence. Validation errors are supplied to corrective retries. Versions are stored with results for Day 6 evaluation.
