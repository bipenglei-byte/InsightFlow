# Feedback Analyzer V2

Version: `feedback-analyzer-v2`

V2 keeps the V1 controlled vocabulary and severity rubric, then adds explicit category boundaries: latency/resource use is performance-first; navigation/layout/discoverability is UX-first; deterministic malfunction is bug-first. Multi-issue feedback uses the issue with greatest workflow impact. Four compact boundary examples clarify performance vs UX, bug behavior, and user-need abstraction.

This is a candidate prompt. It has not been evaluated against a live model in the current environment.
