# Demo Recording Checklist

- [ ] Production/demo environment works
- [ ] NovaNote demo dataset is loaded
- [ ] No browser-console errors
- [ ] No secret or private path is visible
- [ ] Browser zoom is reset
- [ ] Correct starting route is open
- [ ] Demo Mode or Live AI is clearly indicated
- [ ] Browser chrome and unrelated tabs are hidden
- [ ] 1440p recording is selected when available
- [ ] Cursor movement is slow and intentional
- [ ] No unnecessary scrolling
- [ ] Charts and fonts have loaded
- [ ] Final recording is 60–90 seconds
- [ ] Claims match the implemented product and evaluation artifacts
