# Project Summary

InsightFlow 是面向产品经理的 AI 用户研究与产品洞察平台，将 CSV/XLSX 中的非结构化反馈转换为结构化 Feedback、可追溯 Pain Point、User Need、Requirement、Priority、Product Opportunity 与可编辑 PRD。项目完整覆盖产品定义、PRD、设计系统、高保真 MVP、OpenAI-compatible AI Pipeline、Zod Schema、Evidence Tracking、Prompt Evaluation 与部署准备。核心设计不是让 AI 替代决策，而是通过原始 Evidence、确定性优先级算法、Business Value Slider 和 Manual Override，为 PM 提供可信、可解释且可干预的决策支持。
